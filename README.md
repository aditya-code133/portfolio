## 📦 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
# Clone repository
git clone https://github.com/aditya-code133/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Run development server (runs on port 3000)
npm run dev
```

Visit `http://localhost:3000/` in your browser.

---

## 🚢 Production Build
```bash
npm run build
```
The optimized client assets are emitted to the `dist/` directory, ready for deployment on GitHub Pages, Vercel, or Cloudflare Pages.
